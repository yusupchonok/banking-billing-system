# Сравнительный анализ Яндекс.Геокодера, DaData и GigaChat

## 1. Цель исследования

Цель работы — сравнить API-контракты и фактические результаты Яндекс.Геокодера, DaData и GigaChat и определить наиболее подходящий сервис для прямого и обратного геокодирования.

В рамках работы проверялись два сценария:

- **прямое геокодирование:** адрес → координаты;
- **обратное геокодирование:** координаты → адрес.

---

## 2. Исходные данные и методика

Для тестирования использована выборка:

- 100 адресов для прямого геокодирования;
- 100 наборов координат для обратного геокодирования;
- 3 исследуемых сервиса.

Всего в массовом прогоне выполнено 600 бизнес-запросов: 300 запросов прямого и 300 запросов обратного геокодирования.

Перед автоматизированным прогоном API-контракты были проверены вручную через Postman:

Для GigaChat дополнительно выполнялся отдельный запрос на получение access token.

Массовый прогон выполнен Python-скриптом. Результаты каждого запроса записывались в Excel.

### Метрики прямого геокодирования

Для каждого сервиса фиксировались:

- HTTP-статус;
- полученные координаты;
- нормализованный адрес;
- показатель качества результата(если он предусмотрен API);
- время ответа;
- ошибка запроса.

Для сравнения результатов вычислялось расстояние между координатами, полученными разными сервисами. Для итогового анализа использовались:

- среднее расстояние;
- медианное расстояние;
- доля результатов с расхождением не более 50 м;
- доля результатов с расхождением не более 100 м.

Медиана используется как более устойчивая метрика, поскольку в выборке присутствуют единичные большие выбросы.

### Метрики обратного геокодирования

Фиксировались:

- HTTP-статус;
- полученный адрес;
- город;
- улица;
- дом;
- время ответа.

Дополнительно сравнивались отдельные компоненты адреса: город, улица и дом. Сравнение выполнялось только для случаев, когда оба сервиса вернули соответствующий компонент.

## 3. Результаты прямого геокодирования

### 3.1 Техническая успешность

| Метрика | Яндекс | DaData | GigaChat |
|---|---:|---:|---:|
| Успешные HTTP-запросы | 100% | 100% | 100% |
| Получены координаты | 100% | 100% | 100% |
| Среднее время ответа | 544.65 мс | 542.76 мс | 523.50 мс |
| Медианное время ответа | 551.50 мс | 559.50 мс | 440.00 мс |

Все три сервиса технически вернули координаты для всей выборки. Поэтому сам факт HTTP 200 не позволяет оценить качество результата.

### 3.2 Показатели качества специализированных геокодеров

Для Яндекс.Геокодера распределение `precision`:

| Значение | Количество | Доля |
|---|---:|---:|
| `exact` | 84 | 84% |
| `number` | 14 | 14% |
| `near` | 2 | 2% |

Для DaData распределение `qc_geo`:

| Код | Количество | Доля |
|---|---:|---:|
| `0` — точные координаты дома | 83 | 83% |
| `1` — ближайший дом | 13 | 13% |
| `2` — улица | 4 | 4% |

По внутренним метрикам качества Яндекс и DaData показали близкий результат: точный дом определён в 84% и 83% случаев соответственно.

### 3.3 Совпадение координат между сервисами

| Метрика | Yandex ↔ DaData | Yandex ↔ GigaChat | DaData ↔ GigaChat |
|---|---:|---:|---:|
| Среднее расстояние | 80.87 м | 44442.58 м | 44471.86 м |
| **Медианное расстояние** | **7.56 м** | **4619.41 м** | **4616.55 м** |
| ≤ 50 м | 87% | 0% | 0% |
| ≤ 100 м | 93% | 0% | 0% |
| Максимальное расхождение | 4496.02 м | 681387.42 м | 681421.80 м |

**Яндекс и DaData показали высокую согласованность:** медианное расхождение составило всего 7.56 м, а 93% результатов находятся в пределах 100 м друг от друга.

GigaChat заметно расходится с обоими специализированными сервисами: медианное отклонение составляет около 4,6 км, а ни один результат не оказался в пределах 100 м одновременно с результатом Яндекса или DaData.

## 4. Результаты обратного геокодирования

### 4.1 Получение и детализация адреса

| Метрика | Яндекс | DaData | GigaChat |
|---|---:|---:|---:|
| Успешные HTTP-запросы | 100% | 100% | 100% |
| Получен адрес | 94% | 96% | 94% |
| **Определён дом** | **94%** | **73%** | **46%** |
| Среднее время ответа | 520.40 мс | 525.05 мс | 656.18 мс |
| Медианное время ответа | 520.50 мс | 526.50 мс | 617.50 мс |

По полноте адреса DaData немного чаще возвращала какой-либо адрес — 96% против 94% у Яндекса. При этом Яндекс значительно чаще определял объект **до уровня дома**: 94% против 73% у DaData и 46% у GigaChat.

### 4.2 Совпадение компонентов

Совпадение считается среди строк, в которых оба сравниваемых сервиса вернули соответствующий компонент.

| Компонент | Yandex ↔ DaData | Yandex ↔ GigaChat | DaData ↔ GigaChat |
|---|---:|---:|---:|
| Город | 95.60% (87/91) | 15.12% (13/86) | 15.73% (14/89) |
| Улица | 78.67% (59/75) | 2.38% (1/42) | 2.50% (1/40) |
| Дом | 52.05% (38/73) | 0.00% (0/44) | 0.00% (0/35) |

Яндекс и DaData практически всегда совпадают на уровне города, но расхождения увеличиваются на уровне улицы и дома. Это показывает, что для строгой оценки абсолютной точности спорные случаи требуют отдельного эталона.

Совпадение GigaChat со специализированными геокодерами находится на низком уровне: по дому совпадений в сравнимых случаях не зафиксировано.

## 5. Сравнение сервисов

| Критерий | Яндекс.Геокодер | DaData | GigaChat |
|---|---|---|---|
| Специализированный API геокодирования | Да | Да | Нет |
| Прямое геокодирование | Да | Да | Через генерацию модели |
| Обратное геокодирование | Да | Да | Через генерацию модели |
| Контракт | Один GET endpoint | Два POST endpoint | OAuth + chat/completions |
| Структурированные компоненты адреса | Да | Да | Только если запросить модель |
| Показатель качества | `precision`, `kind` | `qc_geo` | Специализированного показателя нет |
| Результат forward на выборке | Высокая согласованность с DaData | Высокая согласованность с Яндексом | Сильные расхождения |
| Дом в reverse | **94%** | 73% | 46% |
| Географическое ограничение | Не ограничен только РФ в контракте | Только Россия | Не является геокодером |
| Подход для production-геокодирования | **Подходит** | Подходит | Не рекомендуется |

## 6. Вывод и рекомендация

По результатам исследования **рекомендуется использовать Яндекс.Геокодер как основной сервис прямого и обратного геокодирования**.

Основания:

1. В прямом геокодировании результаты Яндекса и DaData очень близки: медианное расхождение всего **7.56 м**, а **93%** координат находятся в пределах 100 м.
2. Внутренний показатель качества Яндекса `precision=exact` получен в **84%** тестов, что сопоставимо с `qc_geo=0` DaData — **83%**.
3. В обратном геокодировании Яндекс определил дом в **94%** случаев, DaData — в 73%.
4. Яндекс использует единый специализированный endpoint для обоих направлений геокодирования и возвращает `precision`, `kind`, структурированный адрес и координаты.
5. GigaChat показал технически успешные ответы, но результаты плохо совпадают со специализированными сервисами. Поэтому генеративную модель нельзя использовать как основной источник географических координат или адресов.

**DaData может рассматриваться как альтернативный или дополнительный сервис**, особенно если в системе важны нормализация российских адресов и дополнительные структурированные адресные данные. При этом прямое геокодирование DaData относится к сервису стандартизации и оплачивается отдельно после тестового объёма.

**GigaChat не рекомендуется использовать как сервис геокодирования.** Его целесообразно рассматривать только для вспомогательной обработки естественного языка, например для предварительного разбора пользовательского текста перед обращением к специализированному геокодеру.

### Ограничение вывода

Рекомендация основана на статистике совпадения сервисов, детализации reverse-ответов и анализе API-контрактов. Поскольку независимый эталон отсутствует, утверждать абсолютную точность Яндекса или DaData на всей выборке нельзя. Для отдельной оценки точности необходимо дополнительно сформировать эталонный набор и вручную проверить спорные случаи.
